# CINEMA+ v11 — تحسينات شاملة

هذه النسخة مبنية على v10 وتحتفظ بتصميمها ومزاياها.

## التحسينات
- التحميل التلقائي لنتائج البحث أيضًا مع الحفاظ على عبارة البحث.
- منع تكرار نتائج TMDB عند تحميل صفحات إضافية.
- معالجة حالات فشل تحميل الصفحة التالية مع إمكانية إعادة المحاولة.
- إصلاح تتبع الصفحات في الأقسام التحريرية ذات مصادر الأفلام والمسلسلات المتعددة؛ لا تُطلب صفحات بعد نهاية أي مصدر.
- الحفاظ على إصلاح الكتابة في مربع البحث، وقوائم المنصات، والتحميل التلقائي.
- ستة أقسام رئيسية بأسماء مختصرة و10 أعمال في الصف.

## التركيب
ارفع جميع ملفات المشروع إلى GitHub وانتظر إعادة النشر على Vercel.

## المتغيرات
`VITE_TMDB_API_KEY` أو `VITE_TMDB_READ_TOKEN` مطلوب. `VITE_OMDB_API_KEY` اختياري.

## تنبيه
مصادر TMDB وAniList وTVmaze توفر معلومات وصفية وليست روابط مشاهدة. لم يتم اختبار الموقع المنشور أو API مباشرة.
