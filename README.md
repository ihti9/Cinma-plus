# CINEMA+ — جميع التحديثات

نسخة كاملة موحدة للموقع (وليس مجرد ملف تصحيح).

- إصلاح مربع البحث والمحافظة على تركيز الكتابة.
- قوائم المنصات مثل Netflix: جلب الأفلام والمسلسلات، منطقة US، وزر عرض المزيد للصفحات المتاحة.
- ستة أقسام للصفحة الرئيسية: أعمال سعودية، دراما خليجية، عالم الأنمي، دراما أمريكية، أكشن وإثارة، جريمة وغموض.
- عشرة أعمال في الصف الواحد مع عرض الكل، وجلب صفحات إضافية.
- TMDB أساسي، TVmaze وAniList للمعلومات الإضافية، وOMDb اختياري بمفتاح API.
- بدون ويكيبيديا أو Wikidata.

## التركيب
ارفع الملفات الستة إلى جذر مشروع GitHub مع الاحتفاظ بإعدادات Vercel ومتغيرات TMDB الموجودة.

ملاحظة: ظهور النتائج مرتبط ببيانات TMDB وتوفر مزودي المشاهدة حسب المنطقة؛ منطقة US لا تعني إتاحة المشاهدة في السعودية.


## v10 — التمرير التلقائي
- في قوائم Netflix والمنصات والتصنيفات و«عرض الكل» والأفلام والمسلسلات: يجلب الموقع النتائج تلقائياً عند الاقتراب من نهاية القائمة.
- تبقى 10 بطاقات فقط مبدئياً في صفوف الصفحة الرئيسية.
- لا حاجة إلى زر «عرض المزيد»؛ يظهر مؤشر تحميل بسيط بدلاً منه.
- عند عدم دعم المتصفح IntersectionObserver يظهر زر نصي احتياطي قابل للضغط.
